# BEAR-game.

Inspired by the legendary game made by Google Snake, it uses the same style of gameplay using the arrow keys and buttons, but with a Bear trying to grow by chasing honey! Don't go into yourself, as you do grow with each honey collected, or hit the walls, or else you lose! Try and get as many honey blocks to reach a new high score or win!

Move the snake around to grow, use the arrow keys or buttons, and just have fun! 

This was coded in HTML as well as JavaScript and took ~ 10 hours to fully code, mostly tweaking and also adding more features and also mainly focusing on emulating that classic snake game style, this was really one of the projects that taught me java and also got me into making HTML sites. I do code in C++ normally so it was pretty easy to learn but it was also a challenge to look into coding it! 

I hope you enjoy playing, more projects in the future!
